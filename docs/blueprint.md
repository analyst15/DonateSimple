# **App Name**: DonateSimple

## Core Features:

- Donation Tiers: Display donation tiers: Show predefined donation amounts with descriptions.
- Payment Form: Secure payment form: Collect donor information and process payments via Stripe or PayPal integration.
- Confirmation: Confirmation message: Display a thank you message with donation details upon successful transaction.

## Style Guidelines:

- Primary color: Use a calming blue (#3498db) to inspire trust.
- Secondary color: Implement a clean white (#ffffff) background for readability.
- Accent: A warm green (#2ecc71) for success messages and key actions.
- Clean and readable sans-serif font.
- Simple and intuitive layout with clear calls to action.
- Use simple, recognizable icons to represent different donation tiers or causes.
